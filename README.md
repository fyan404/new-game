# new-game
这是一个极其粗略的demo版，可以看看，如果有时间可能会更新一下
This is a very rough demo version, you can take a look, and if there's time it might get updated.

Windows 系统：
桌面右键 → 新建「文本文档」
打开文档，把全部游戏代码粘贴进去，保存关闭
重命名文件：把 新建文本文档.txt 改成 game.html
看不到后缀：文件夹顶部「查看」→ 勾选文件扩展名
双击 game.html，自动用 Edge/Chrome 打开，直接玩

Windows System：
Right-click on the desktop → New → Text Document
Open the document, paste all the game code in, save and close
Rename the file: change New Text Document.txt to game.html
Can't see the extension: at the top of the folder, click View → check File name extensions
Double-click game.html, it will open automatically in Edge/Chrome, and you can play directly

Mac 系统：
打开「文本编辑」，粘贴代码
顶部菜单：文件 → 存储
名称填 game.html，格式选纯文本
双击文件，用 Safari/Chrome 打开

Mac System：
Open TextEdit, paste the code
Top menu: File → Save
Name it game.html, choose Plain Text format
Double-click the file to open it in Safari/Chrome
